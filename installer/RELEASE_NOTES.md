## Install Scram MCP

**Windows:** download **Scram-MCP-Setup-….exe** below and double-click it. The installer asks who it's for ("Only for me" needs no admin rights) and where to install it, then adds **Scram MCP** to the Start menu and desktop. Afterwards, open it from the desktop icon or the Start menu.
Windows may say "Windows protected your PC", because the installer isn't code-signed yet: click **More info**, then **Run anyway**. That's needed once.

**Mac:** download **Scram-MCP-…-mac.dmg** below, open it, and drag **Scram MCP** into Applications. The first time you open it, macOS blocks it, because it isn't signed with an Apple certificate yet: open **System Settings → Privacy & Security**, scroll down, and click **Open Anyway** next to Scram MCP. That's needed once.

## Then

1. Log in to Scram in the Scram MCP window.
2. In its menu, click **Scram MCP → Connect Claude Code**. (You need [Claude Code](https://code.claude.com/docs/en/setup) installed.)
3. Start Claude Code (`claude` in a terminal) and ask it to build something in Scram.

Keep the Scram MCP window open while Claude works in Scram. To stop, close the window.
